# Rugy Platformer

A whimsical Persian-rug-inspired 2.5D platformer prototype built in Unity with a handcrafted fantasy aesthetic.

![Rugy hero art](Assets/Art/Characters/RugyPlayer.png)

## Overview

Rugy is a cozy, magical platformer concept set in a floating world of woven carpets, glowing lanterns, and deep indigo skies. The visual language mixes plush textile textures, ornate geometric patterns, warm gold accents, and soft magical lighting to create a tactile, storybook world.

This prototype focuses on:

- Side-scrolling 2.5D platforming
- Soft, readable movement and jump feel
- Rug-themed environment and characters
- Handcrafted fantasy art direction
- Modular world props and reusable visual assets

## Project Theme

The project leans into a whimsical Persian-carpet fantasy style:

- Crimson wool textures and embroidery
- Turquoise and saffron color accents
- Floating carpet fragments and tassels
- Ancient courtyard architecture with mystical lighting
- Warm and cozy, but still adventurous and mysterious

## Structure

```text
Assets/
  Art/
    Characters/
    Environment/
  Scripts/
    Camra/
    Player/
    World/
    Enemies/
ProjectSettings/
Packages/
```

Key gameplay code is organized under the Unity `Assets/Scripts` tree, with player, camera, enemy, and world logic split into dedicated folders.

## Design Notes

The project follows a flexible Unity URP setup and is built around a 2.5D platforming feel. The intended experience emphasizes:

- Clear, readable movement and jumping
- A soft, fuzzy visual identity
- Layered floating platforms and handwoven structures
- Exploration through magical, dreamlike architecture

## Getting Started

1. Open the project in Unity.
2. Load the main scene from the `Assets/Scenes` folder.
3. Enter Play Mode to test the prototype.
4. Iterate on gameplay, visuals, and environment props in small steps.

## Tools / Stack

- Unity
- URP (Universal Render Pipeline)
- C# scripting
- 2.5D gameplay prototype structure
